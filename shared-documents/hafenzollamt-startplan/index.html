Resend: Absender ahz@ipm-kg.de

Warum zuerst: Die DNS-Einträge bekommst du erst, wenn die Domain in Resend angelegt ist. Du setzt sie direkt in der DNS-Verwaltung von ipm-kg.de; sobald Resend „Verified" anzeigt, ist die komplette Mailkette scharf (Benachrichtigung, Bestätigung, Login-Code der Leadliste).

Du

  2. Links Domains → Add Domain.
  3. Domain: ipm-kg.de · Region: Europe (Ireland) → Add.Die Region ist wichtig (EU-Server, steht so in der Datenschutzerklärung).
  4. Es erscheinen 3 DNS-Einträge (DKIM als TXT, SPF als TXT und ein MX, meist für die Unterdomain send). Diesen Tab offen lassen.
  5. Zweiten Tab: DNS-Verwaltung von ipm-kg.de (beim Hoster/Registrar) öffnen → die drei Einträge exakt anlegen: Typ, Name (Host) und Wert aus Resend kopieren; TTL egal.Typische Stolperfalle: Manche Hoster hängen die Domain automatisch an den Host an — dann nur den Teil vor „.ipm-kg.de" eintragen (z. B. resend._domainkey statt resend._domainkey.ipm-kg.de).
  6. Zurück in Resend → Verify klicken. Status wird „Verified" (manchmal nach 5–15 Minuten; solange weiter mit Phase 2).
  7. Links API Keys → Create API Key → Name AHZ Worker · Permission Sending access · Domain ipm-kg.de → Create.
  8. Key kopieren und in die Datei C:\Website-Business\Websiten\altes-hafenzollamt\.secrets.local schreiben, eine Zeile: RESEND_API_KEY=re_… (Datei neu anlegen; sie ist vom Repo ausgeschlossen).

Phase 3b · Videos · heute oder morgen

Nach Tag 5–7 zeigt der Vergleich Bild gegen Video je Thema, was funktioniert; dann rücken zwei bis drei weitere Videos als Reserve nach.

FormatEin Schnitt, zwei Zuschnitte: 4:5 (1080×1350, Feed) und 9:16 (1080×1920, Reels/Stories). 10–12 Sekunden, davon die letzten 3 Sekunden Endkarte.
Text statt TonDer Hook steht in Sekunde 0–2 eingebrannt im Bild — Feeds laufen stumm. Ohne Sprecher liefern; Ton ist Zugabe (unten).
BewegungLangsamer Push-in (1,00 → 1,06 über 4–5 s) oder sanfter Schwenk. Keine Schnitte unter 2,5 s, keine Effekte. Keine Gesichter, kein anderes Gebäude.
Echte ElementeAlles aus der Seite liegt fertig als PNG bereit: Buttons (3 Frames für die Sweep-Animation), Logo, Headlines in Playfair (dunkel und weiß), Quiz-Karten, Schritte-Karten, fertige Endkarten, Farbkarte, Schriften.
